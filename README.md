# ミエグレヒーローズ

ブラウザで遊べるベルトスクロールアクションゲーム。
STAGE 1「三重重工正門」／ STAGE 2「三重重工ダム」 ― BLACK DEATH襲来 守れ本社工場編 ―

## 遊ぶ

- **本編**：https://sattimaxy-hue.github.io/miegure-heroes/
- **ミエグレ外伝 正門突破**（ミニゲーム単体）：https://sattimaxy-hue.github.io/miegure-heroes/gaiden/
- **Light版**（絵を軽くした版。古いスマホ向け）：https://sattimaxy-hue.github.io/miegure-heroes/light/
- **ボステスト**（ボスとすぐ戦える・技を選んで出させられる確認用）：https://sattimaxy-hue.github.io/miegure-heroes/boss-test/

スマホでもパソコンでも、開くだけで遊べる（インストール不要）。
パソコンは キーボード（←→↑↓・Z／X など）、スマホは画面のボタンで操作。
くわしい遊び方は [はじめにお読みください.txt](はじめにお読みください.txt) を見てな。

## 中身

| 場所 | 中身 |
|---|---|
| `index.html` | 本編（画像・音・プログラムが全部この1つに入ってる） |
| `intro.mp4` | オープニングムービー（`index.html` と同じ場所に置く） |
| `gaiden/index.html` | ミニゲーム「ミエグレ外伝 正門突破」の単体版 |
| `light/index.html` | Light版（絵を半分の細かさにした軽い版。オープニング動画も中に入ってる） |
| `boss-test/index.html` | ボステスト（確認用。本編フル版から作る） |
| `handheld/` | 携帯ゲーム機（Linux中華機など）向けのキット |
| `はじめにお読みください.txt` | 遊び方の説明書 |
